# Topic lenses

이 파일은 주제에 맞는 예시를 고를 때만 읽는다. 모든 내용을 한 번에 불러오지 않는다.

## Network

- 기본 흐름: 애플리케이션 → 소켓 → 전송 계층 → 라우팅 → 링크 → 상대 호스트
- 핵심 대비: 지연·손실·순서·재전송·상태 관리
- 적용 질문: 패킷이 사라지거나 순서가 바뀌면 어느 계층이 무엇을 책임지는가?

## AI

- 기본 흐름: 데이터 → 표현 → 학습 신호 → 모델 추론 → 평가 → 배포·관찰
- 핵심 대비: 학습과 추론, 파라미터와 컨텍스트, 정확도와 비용·지연
- 적용 질문: 같은 모델인데 결과가 달라지는 입력·상태·평가 요인은 무엇인가?

## Data center

- 기본 흐름: 전력·냉각 → 서버·가속기 → 네트워크 → 스토리지 → 오케스트레이션
- 핵심 대비: 용량과 성능, 장애 도메인, 중복성, 열·전력 예산
- 적용 질문: 병목이 계산·메모리·네트워크·전력 중 어디인지 어떻게 측정할 것인가?

## English

- 기본 흐름: 상황 → 의도 → 기본 문장 → 자연스러운 변형 → 즉시 말하기
- 핵심 대비: 직역과 관용 표현, 문법적 정답과 실제 자연스러움, 수동 인식과 능동 산출
- 적용 질문: 이 표현을 실제 대화에서 한 문장으로 바꿔 말하면 어떻게 되는가?

## AX

- 기본 흐름: 업무 목표 → 현재 프로세스 → AI가 맡을 판단·생성·검증 → 사람 승인 → 측정
- 핵심 대비: 자동화와 증강, 속도와 품질, 편의와 통제, 데모와 운영
- 적용 질문: 사람이 꼭 남아야 하는 판단과 자동화해도 되는 반복 작업은 무엇인가?
